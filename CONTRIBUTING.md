# Contributing to Regent Agent

Regent Agent first-party contributions are submitted under the Apache License 2.0, Section 5.

## Contribution requirements

- Sign off each commit with `Signed-off-by` (DCO).
- Confirm that you have the right to submit the contribution.
- Do not assign copyright by contributing.
- Record the source, version, and license of third-party material.
- Do not include secrets, credentials, private tenant data, or unlicensed assets.
- Keep changes focused and include tests or validation evidence when applicable.

## Pull requests

A pull request should describe:

- The problem and intended behavior.
- The files and contracts changed.
- Validation performed.
- Any dependency, license, API, schema, or migration impact.

Third-party code, strong-copyleft dependencies, new public assets, and license changes require explicit review.

By submitting a signed-off contribution, you confirm that the contribution may be distributed under the project's Apache-2.0 license.
