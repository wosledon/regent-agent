# 40 成本归属、分摊与异常

- 版本：v0.1（待评审）
- 范围：成本归属、公共成本、项目预算、结转、异常、币种和对账
- 对应需求：FR-083、BR-137、BR-138、BR-139、BR-140、BR-141
- 对应缺口：G-55

## 1. 核心规则

1. 钱账是唯一成本事实，编制账不记录费用。
2. 员工、岗位、项目和公共成本是同一账目的不同视图，不得重复计费。
3. 模型费用以 Gateway 用量为权威，工具费用以 Runner 用量为权威。
4. 账本只增不改，价格和账单差异通过新条目表达。
5. 成本归属必须显式；无法归属时进入 `Unallocated`，不得猜测。
6. 公共成本默认不自动分摊。
7. 项目预算不自动结转。
8. 第一梯队只使用确定性异常规则，不使用机器学习自动处罚。

## 2. 成本维度

```text
LedgerEntry:
  id, tenant_id, usage_event_id
  occurred_period, posted_period
  employee_id?, position_id?, project_id?
  cost_center_type, cost_center_id?
  account_type
  amount, currency, price_version
  entry_type, corrects_entry_id?
```

- `employee_id` 和 `position_id` 是发生时快照，调岗和离职不改写。
- `project_id` 可空；公共成本使用 `CompanyOverhead`，无法归属使用 `Unallocated`。
- 同一账目可以同时具有员工、岗位和项目维度，但金额只计算一次。
- `corrects_entry_id` 指向原条目，不覆盖原条目。

## 3. 归属优先级

| 情况 | 归属 |
|---|---|
| Usage 带有效 `task_id` | 任务所属项目，并记录执行员工和当时岗位 |
| 无任务，带有效显式 `project_id` 或成本中心 | 指定项目或成本中心 |
| Butler 会话绑定项目 | 指定项目 |
| Butler、公共评测、平台维护、基础设施无项目 | `CompanyOverhead` |
| 引用无效、跨租户或无法判断 | `Unallocated` 并生成治理任务 |

- 控制面不根据员工当前项目猜测历史归属。
- 跨租户引用一律拒绝并记录安全事件。
- `Unallocated` 必须在 24 小时内进入处理队列，超过 72 小时未解决计入指标。

## 4. 公共成本与分摊

默认进入 `CompanyOverhead`：

- 无项目 Butler 会话。
- 通用模型评测和能力矩阵维护。
- 组织治理、审计、备份和平台维护。
- 共享 Runner、存储和网络成本。

显式分摊：

```text
CostAllocationRule:
  id, tenant_id, name
  source_cost_center_id
  targets[{project_id, weight_bps}]
  effective_from, effective_to
  version, status, approved_by, approval_ref
```

- 权重使用基点，合计必须为 10000。
- 规则必须版本化、限时、可撤销并保留审批。
- 支持固定权重或实际用量权重；实际用量必须可追溯。
- 分摊结果只生成 `CostAllocationResult` 投影，不生成新费用。
- 租户总成本、员工成本和公共成本原始金额保持不变。
- 规则变化只影响后续归属，不静默重算已关闭周期。

## 5. 项目预算

- 项目批准时设置 `BudgetEnvelope`，包含金额、币种、周期和软硬类型。
- 项目预算从租户预算中分配，不额外创造额度。
- 活跃项目预算、公共成本预算和租户预算必须同时可见。
- 项目预算默认 `Soft`，达到 100% 暂停新任务并评审。
- 项目预算可经审批设为 `Hard`，硬限制下 Gateway 和工具执行必须原子预留。
- 项目终止后停止新预留，在途任务按安全点结算。
- 项目成本 = 直接成本 + 已批准分摊投影，展示时注明两部分。

## 6. 预算结转

- 默认不自动结转。
- 只有所有者或有效所有者委托可批准项目预算结转。
- 可结转金额只能来自未使用、未预留、无欠款的项目预算。
- 预留、欠款、超支、供应商未结账单和已关闭项目余额不得结转。
- 结转生成 `BudgetCarryover`，记录来源周期、目标周期、金额、理由和审批。
- 结转额度只在目标周期有效，不跨多个周期自动滚动。
- 结转不增加租户硬预算，也不改写原周期账目。

## 7. 确定性异常

```text
CostAnomaly:
  id, tenant_id, rule_id, rule_version
  subject_type, subject_id
  severity, status
  observed_value, threshold_value, currency
  evidence_refs, detected_at
  dedupe_key, resolution_ref?
```

### 7.1 规则

| 规则 | 阈值 | 动作 |
|---|---|---|
| 任务预算耗尽 | 实际或承诺成本达到 100% | 暂停并沿管理链评审 |
| 岗位任务成本异常 | 超过近 30 天同类完成任务日均成本 3 倍，样本 ≥5 | L1，通知直接 Leader |
| 项目预算超支 | 实际或预测超过预算 120% | L2 告警 |
| 租户预算预测 | 预测超过月度硬预算 100% | L2 告警 |
| 租户严重预测 | 预测超过月度硬预算 110% | L3 告警并冻结非必要任务 |
| 模型价格变化 | 同 Provider + Model ID 在 24 小时内有效价格变化超过 20% | 停止自动路由并重新评估 |
| 供应商账单差异 | 超过月度账单 1% 或租户配置绝对阈值 | 进入对账队列 |
| Butler 失败仍计费 | 同一 Butler Job 连续 3 次失败且产生费用 | 单列异常项 |

- 岗位基线使用近 30 天已完成、同 Task Type、同复杂度权重段的平均值。
- 样本不足 5 条时标记 `InsufficientEvidence`，不触发岗位成本异常。
- 预测使用版本化策略，默认按近 7 日平均日消耗乘剩余天数，加上已承诺和预留金额。
- 所有阈值、基线窗口和预测策略版本化，变化只影响后续检测。

### 7.2 处置边界

- 异常只生成 Finding、告警和证据，不自动修改预算、模型或岗位。
- 任务 100% 和租户硬限制触发既有暂停、评审和升级。
- 价格异常停止自动路由，不自动跨模型降级。
- 成本异常不得单独作为降职、冻结或解雇依据。
- 绩效必须结合复杂度、失败原因、返工、质量和独立复核。
- 同一主题同一天按 `dedupe_key` 合并，持续超限可更新状态但不重复刷告警。

## 8. 币种

- 金额使用最小货币单位整数。
- 只保存原币金额和 ISO 4217 币种。
- 不同币种分别统计，不直接相加，也不做自动汇率换算。
- 跨币种汇总不在当前范围，界面按币种分组展示。
- 未知价格仍标记 `Unpriced`，不得按 0 处理。

## 9. 迟到费用与对账

- 迟到 Usage 归入 `occurred_period`，记账记录 `posted_period`。
- 未关闭周期直接入账并更新投影。
- 已关闭周期的差异在当前开放周期生成更正条目，引用原条目。
- 月度账单对账生成 `ReconciliationCase`，支持 matched、adjusted、disputed 和 unresolved。
- 重复 `source_event_id` 去重，不生成异常费用。
- 超过 72 小时未解决的对账差异进入治理队列。

## 10. 预算偏差口径

- 偏差率 = `(实际成本 - 预算) / 预算`。
- 项目预算偏差目标为 ±10% 内。
- 超过 ±20% 生成预警。
- 预算为 0、缺失或币种不一致时不计算比例，标记 `NotComparable`。
- 该口径统一用于 PRD、项目管理、绩效和仪表盘。

## 11. 实体

- `CostAllocationRule`：公共成本显式分摊规则。
- `CostAllocationResult`：分摊投影，不新增费用。
- `BudgetEnvelope`：项目或公共成本预算。
- `BudgetCarryover`：显式预算结转。
- `CostAnomaly`：确定性成本异常。
- `ReconciliationCase`：供应商账单和用量对账。

## 12. 指标

| 指标 | 目标 |
|---|---:|
| 成本归属覆盖率 | 100% |
| 超 72 小时未解决对账差异 | 0 |
| 预算预测告警延迟 | ≤5 分钟 |
| 项目预算偏差 | ±10% 内 |
| 自动预算结转次数 | 0 |
| 分摊权重错误规则数 | 0 |

## 13. 测试场景

1. 同一 Usage 只生成一条钱账记录。
2. 任务费用归项目并保留员工、岗位快照。
3. 调岗后历史岗位不变化。
4. 无项目 Butler 费用进入公共成本。
5. 无效或跨租户项目引用进入 Unallocated 并记录安全事件。
6. 公共成本默认不分摊。
7. 分摊权重不为 100% 时拒绝规则。
8. 分摊结果不增加租户总成本。
9. 项目预算达到 100% 时暂停评审。
10. 项目硬预算与租户硬预算同时原子预留。
11. 未审批不能结转预算。
12. 预留、欠款和超支不能结转。
13. 岗位样本不足 5 条时不触发成本异常。
14. 同类任务成本超过 3 倍时生成 L1。
15. 项目预测超过 120% 时生成 L2。
16. 租户预测超过 100%/110% 时分别生成 L2/L3。
17. 价格 24 小时变化超过 20% 时停止自动路由。
18. 账单差异超过阈值时生成对账案件。
19. 成本异常不自动改预算、换模型或惩罚员工。
20. 不同币种分别统计且不直接相加。
21. 迟到费用归发生周期。
22. 已关闭周期通过当前周期更正且不覆盖原条目。
23. 重复 Usage 不重复入账。
24. 预算为 0 时不计算偏差比例。

## 14. 验收场景

1. 每笔费用都有明确归属状态。
2. 公共成本分摊不重复计费。
3. 项目预算不自动结转。
4. 异常规则可由版本化阈值复现。
5. 异常不自动改变组织或模型。
6. 不同币种分别展示，不做自动换算。
7. 迟到账单和更正保留完整链路。
8. PRD、绩效和项目管理使用同一 ±10%/±20% 口径。
