# 24 内容安全

- 版本：v0.1（待评审）
- 范围：内容政策、检测管线、分级处置、申诉、证据、对外发布和合规
- 对应需求：FR-066、BR-078、BR-079、BR-080
- 对应缺口：G-37

## 1. 目标与边界

- 正常创作、软件开发和授权安全研究不受干扰。
- 只对违法、侵权、冒充和明确红线内容强制处置。
- 分类器不是唯一法律判断。
- 默认只限制违规内容或动作，不冻结员工全部工作。
- 误报可申诉，员工不因报告风险或误报受处罚。

## 2. 适用范围

- 用户输入。
- 员工生成内容。
- 聊天和消息。
- Tool 返回内容。
- 代码、文档、图片、音视频和截图。
- 记忆和知识库。
- 发布包和对外输出。

## 3. 内容分级

| 级别 | 示例 | 默认动作 |
|---|---|---|
| Allowed | 正常软件、文档、设计、研究 | 自动 |
| AllowedWithLabel | 讽刺、虚构、敏感话题、授权安全研究 | 自动并标记 |
| Restricted | 双用途安全、成人、暴力、争议政治 | 按场景和授权 |
| RequiresReview | 疑似侵权、冒充、欺骗、灰色业务 | 暂停相关动作并复核 |
| Prohibited | 明确违法、儿童剥削、欺诈、恶意软件、严重侵权 | 阻止并升级 |

合法安全测试和恶意软件分析只能在授权沙箱内进行，不能直接发布或攻击外部系统。

## 4. ContentSafetyPolicy

```text
policy_id
tenant_id
version
jurisdiction
industry_profile
categories[]
detector_refs
disposition_rules
external_egress_rules
appeal_policy
effective_from
```

- 政策版本化并审计。
- 租户可提高保护，不能关闭平台红线。
- TaskRun、Artifact 和发布记录绑定政策版本。
- 政策变化只影响新任务，在途任务按原策略安全结束或暂停。

## 5. 检测管线

```text
内容
  → 类型和来源识别
  → 确定性规则
  → 分类器/moderation
  → 代码、URL、许可证和恶意软件扫描
  → 风险分级
  → 处置
```

检测后端可插拔：

- 本地规则和模型。
- Provider 原生 moderation。
- 外部安全服务。
- 人工复核。

检测结果记录 detector_version、policy_version 和 confidence，不只保存最终标签。

## 6. 处置

| 处置 | 行为 |
|---|---|
| Allow | 正常继续 |
| AllowWithLabel | 加标签、限制传播范围 |
| Sanitize | 移除违法或危险部分后继续 |
| RequiresReview | 暂停发布、外发或高风险动作 |
| Block | 拒绝内容或动作 |
| Quarantine | 隔离内容，只保留受控证据 |
| Escalate | L2/L3 安全事件 |

- 默认不冻结员工全部工作。
- 红线事件可暂停相关 Task、Tool Profile 或租户功能。
- 员工可换用合规方案继续。
- 内容安全通过不替代发布审批。

## 7. 输入与生成

### 输入

- 明显违法请求直接拒绝。
- 模糊请求先澄清用途、授权和目标。
- 用户指令不构成合规豁免。

### 生成

- 生成后、持久化前扫描。
- 对外发布前再次扫描。
- 代码同时检查恶意行为、秘密、许可证和供应链。
- 模型拒绝或安全拦截记录原因码，不保存不必要原文。

## 8. 对外动作

以下动作必须通过内容安全门禁：

- 发布网站或应用。
- 发送邮件、消息或 Webhook。
- 提交公共仓库。
- 上传第三方平台。
- 调用外部 API 生成公开内容。
- 广告、营销和社交媒体内容。

对外动作仍需原有权限、预算和审批。

## 9. 侵权与冒充

- 检测明显版权、商标和许可证风险。
- 公共素材需要来源和许可记录。
- 仿冒他人、伪造身份和误导性背书默认复核。
- 讽刺、虚构和新闻按上下文判断，不能只按关键词封禁。
- 侵权投诉进入暂停、取证、复核和下架流程。

## 10. ContentFinding 与复核

```text
finding_id
content_ref
content_hash
policy_version
detector_version
category
risk_level
disposition
evidence_ref
status
```

- 复核者独立于原检测器和内容作者。
- 复核可选择确认、解除、降级、 sanitize 或补充证据。
- 高影响决定需要第二人复核。
- 复核结论进入审计并用于规则校准。

## 11. 申诉与例外

- 员工可提交反证和上下文。
- 例外绑定内容类型、范围、原因、负责人和到期时间。
- 员工不能自行关闭内容安全。
- 误报进入质量指标，不处罚员工。
- 例外到期自动恢复原政策。

## 12. 证据与隐私

普通审计只记录：

```text
content_hash
category
policy_version
detector_version
risk_level
action
reviewer
```

不记录不必要的违法内容原文。

法律取证：

- 单独加密存储。
- 最小权限访问。
- 记录下载和访问。
- 按法律保留策略处理。
- 与普通日志、记忆和遥测隔离。

## 13. 外部合规

- 政策按地区、行业和客户要求版本化。
- 遵守 Provider 使用政策、数据驻留和年龄限制。
- 不把平台规则表述为法律意见。
- 支持下架、投诉、申诉和审计导出。
- 自托管可提高保护，但不能关闭平台红线。

## 14. 与其他机制结合

- Q-019：不可信内容和 TaskGrant。
- Q-021：制品、镜像、依赖和许可证扫描。
- Q-022：DLP 和敏感数据隔离。
- Q-023：审计完整性。
- 现有 L0～L3 告警和管理链升级。

## 16. API 与 Tool

- `GET /content-safety/policies`：查看政策。
- `POST /content-safety/scan`：扫描内容。
- `GET /content-safety/findings`：查看发现。
- `POST /content-safety/findings/{id}/review`：复核。
- `POST /content-safety/findings/{id}/appeal`：申诉。
- `POST /content-safety/exceptions`：申请限期例外。
- `POST /content-safety/takedowns`：发起下架流程。
- 普通员工不能修改政策或自行豁免红线。

## 17. 测试场景

1. 多语言和混淆违法内容。
2. 讽刺、虚构和安全研究误报。
3. 恶意代码与正常安全工具。
4. 侵权素材和许可证冲突。
5. 冒充人类、虚假背书和欺诈页面。
6. 图片、音视频和截图。
7. 公共发布前拦截。
8. 误报申诉和例外到期。
9. 法律取证访问审计。
10. 员工换用合规方案继续任务。
11. 对外动作绕过内容门禁被拒绝。
12. 政策升级后在途任务安全结束。

## 18. 验收场景

1. 正常内容无需人工复核。
2. 模糊内容进入复核而非直接封禁。
3. 红线内容被阻止并升级。
4. 员工不会因误报受到处罚。
5. 对外发布必须通过内容门禁。
6. 普通审计不包含违法内容原文。
7. 法律取证访问独立授权并审计。
8. 政策、检测器和处置版本可追溯。
9. 误报和申诉用于规则校准。
10. 员工可换用合规方案继续安全工作。
