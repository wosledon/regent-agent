# ADR-0012：当前只承诺单租户单机聚合容量

- 状态：Accepted
- 日期：2026-11-23
- 范围：容量、性能和 noisy neighbor

## 背景

MVP 是单租户、自托管、单机部署，需要可验收的容量目标，但不承诺大规模多租户 SaaS。

## 决策

- 基线为 20 员工、40 并行 TaskRun、100 任务/小时、1000 消息/小时、100 模型请求/分钟。
- 2 倍突发持续 15 分钟，24 小时 soak。
- 普通读/写 API P95 分别为 300ms/500ms。
- 队列必须有上限和背压，不得静默丢弃。
- 单租户压测不得使其他租户 API P95 劣化超过 20%，合格任务等待不得超过 30 秒。
- 大规模多租户容量后置。

## 结果

- 容量测试目标明确。
- 避免过度工程化。
- 后续扩容需要新硬件和压测证据。

## 未采用

- 直接承诺大规模 SaaS 容量：缺乏硬件和运营证据。
- 只写“高性能”等不可验收描述。
